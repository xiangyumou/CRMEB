# Core store architecture

The supported clients are the admin Vue 2 application in `template/admin/src` and the H5 / MP-WEIXIN uni-app application in `template/uni-app`. They use existing HTTP endpoints under `crmeb/app/adminapi` and `crmeb/app/api`. Controllers validate requests and delegate to `crmeb/app/services`; DAOs under `crmeb/app/dao` access models under `crmeb/app/model`. Listeners and jobs under `crmeb/app/listener` and `crmeb/app/jobs` handle deferred order and group activity state transitions. The existing route and JSON response contracts remain the boundary.

The checkout path uses `StoreOrderComputedServices` for pricing and `StoreOrderCreateServices` for transactional creation. `OrderCouponCalculator` handles coupon calculation; `OrderFreightCalculator` owns freight-template calculation and cart sums while the original service retains delegating public methods. `StoreOrderServices` reads and updates orders and delegates presentation to `StoreOrderPresentationServices` and admin dashboard statistics to `StoreOrderStatisticsServices`; `StoreOrderRefundServices` manages refunds. Retain transaction, stock, queue and idempotency ordering when extracting responsibilities. `CoreStore` rejects retired business and non-WeChat payment parameters before mutation. The retained marketing services are under `activity/combination`, `activity/advance` and `activity/coupon`.

The admin page builder in `template/admin/src/pages/setting/devise` uses `mobilePage` and `mobileConfig`. Client themes are read by `ThemeServices` and cleaned by `DiyCompatibilityServices`; the same removed-page list in `crmeb/config/core_store_removed_pages.json` is used by the database migration. Existing product and theme IDs, data and media URLs remain authoritative. Customer contact is QR-only through `customer_qrcode`.

`crmeb/public` contains checked-in release output and uploads; it is not the source of the admin or uni-app UI. Production mounts a separate public directory. Compile and verify a coordinated backend/admin/H5/MP-WEIXIN release before rollout. See `build-release.md` and `docs/core-store-reduction.md` for the migration limits.

Run `sh scripts/check-maintenance.sh` for PHP 7.4 lint, regression, and frontend static checks. To lint a changed admin file without rewriting it, run `npm run lint:check --prefix template/admin -- src/path/to/file.vue`; pass each changed path explicitly because the legacy source tree has not undergone a full formatting pass.
