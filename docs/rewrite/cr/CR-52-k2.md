# CR-52-k2: the 50-round concurrency soak cannot run: `vitest` is not found, and its filter matches nothing

**Stream:** K2 (hardening second pass) **Status:** OPEN, for the orchestrator (`.github/**` is not a stream path)
**Files:** `.github/workflows/next.yml`, job `concurrency-soak`, step `50 rounds` (landed from CR-4-k by J3, never yet executed by GitHub Actions)

## What

STAB-001 asks K2 to confirm that the soak's YAML runs the suites it names. It
does not, for two separate reasons.

1. **`vitest` is not a workspace-root binary.** The workflow's
   `defaults.run.working-directory` is `next`, and the step runs
   `corepack pnpm exec vitest run --project int …` there. Only the packages
   depend on vitest, and there is no `next/vitest.config.*` either. Run
   locally from `next/`:

   ```
   $ pnpm exec vitest list --project int 'packages/core/src/**/*.concurrency.int.test.ts'
   ERR_PNPM_RECURSIVE_EXEC_FIRST_FAIL  Command "vitest" not found
   ```

   All 50 rounds would fail in about a second each, and the job would report
   "50 of 50 rounds failed". That reads as 50 flakes.

2. **The filter is a glob, and vitest filters are not globs.** vitest 5's
   `filterFiles` keeps a file when its relative path *contains* the filter
   string (`testFile.includes(f)`). No path contains the literal
   `packages/core/src/**/*.concurrency.int.test.ts`. Even from the right
   directory this would be "No test files found".

The set it names also leaves out SEQ-001 (`order.sequence.int.test.ts`), which
STAB-001 counts as part of the concurrency set.

## Asked for

Replace the `vitest` invocation in the `50 rounds` step with:

```yaml
            if ! corepack pnpm --filter @shop/core exec vitest run --project int \
                 --sequence.seed="$round" --sequence.shuffle \
                 concurrency.int.test.ts order.sequence.int.test.ts \
                 > "soak/round-$round.log" 2>&1; then
```

`--filter @shop/core exec` runs vitest in `packages/core`, where the `int`
project is defined. The redirect is still resolved by the step's shell in
`next/`, so `soak/` and the `upload-artifact` path `next/soak` are unchanged.
The two substrings select the 15 `*.concurrency.int.test.ts` files and SEQ-001.

This is the exact command K2 ran locally for STAB-001, from `packages/core`
with `pnpm exec`: 16 files, 158 tests (2 expected-fail), about 45 s a round on
this machine. See `docs/rewrite/status/k2.md` §STAB-001 for the rounds.
