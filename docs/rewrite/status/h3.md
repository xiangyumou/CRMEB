## Wrapper fixes (brief §2, `api/admin.js`, commit `bfbaba5e6`)

1. `postUserSetLabel` now sends `{ labelIds: string[] }`, one POST per selected customer. Before, it sent `String(array)`.
2. `getUserLabel(0)` used to 422 because `:uid` must match `/^[1-9]\d*$/`.
   - With a real uid, it reads `/staff/users/:uid/labels`.
   - With no uid, it enters "catalogue" mode. The filter drawer and the batch drawer need all labels, and E4 has no catalogue route. So it reads one customer (`GET /staff/users?page=1&pageSize=1`), reads that customer's labels and clears `assigned`. A shop with no customers gets an empty catalogue.
   - The two call sites now call `getUserLabel()` and `getUserLabel(num ? '' : data.uid)`.
3. `postUserSetGroup` passes `null` (clear the group) through as `{ groupId: null }`. Before, it sent `"null"`.
