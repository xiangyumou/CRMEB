`@shop/e2e-admin` 45/45 against that build.

Merge note: turbo 2 runs tasks in strict env mode and `turbo.json` (not H4's) declares no `env`
for `build`, so under `pnpm turbo run build` the variable is filtered out and the default 2
applies. That is the safe direction; to make the override reach a turbo build, add
`"env": ["NEXT_BUILD_CPUS"]` (or `passThroughEnv`) to `build` in `turbo.json`. A direct
`pnpm --filter @shop/web build` or the Docker build sees it as is.
