   R3's own tests and `system/attachment.service.ts`. `guards/src/checks/banned.ts`'s doc comment
   still says `options.fetchImpl ?? fetch` — stale text, not a failure (not R3's file).
8. **Help text**: `app/admin/(shell)/storage/attachments/attachments.tsx` (网址导入 dialog) says
   "只允许公网 http/https 地址" — now https only unless 存储设置 › 允许 http 地址导入 is on. Not an
   R3 path; a one-string follow-up for whoever owns that page.
